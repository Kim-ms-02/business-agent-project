# 디자인 노트

## 분위기 (사용자가 정한 것, 그대로)

> 발표를 앞두고 긴장한 학생이 혼자 연습하는 곳. 차분하고 집중되는 연습실 느낌. 점수보다 '다음에 고칠 한 가지'가 눈에 먼저 들어오게. 너무 귀엽거나 게임 같지 않게.

## 방향: 조용한 연습실의 보면대

- 연습실 벽처럼 살짝 푸른 회색 바탕 위에 흰 종이 한 장(보면대에 올린 대본)을 둔다. 화면마다 종이는 하나이고, 그 안을 가는 선으로 나눈다. 같은 모양의 둥근 카드를 여러 장 늘어놓지 않는다.
- 색은 칠판 초록 하나만 쓴다. 버튼, 지금 하는 일, 그리고 "다음에 고칠 한 가지"에만 쓴다.
- 강조는 한 곳에만 둔다. 리허설 결과에서는 "가장 먼저 고칠 한 가지"(연한 초록 판, 굵은 왼쪽 선, 목표는 큰 글자)가 맨 위에 온다. 점수 숫자는 그 아래에 작게 둔다.
- 질문 연습에서는 질문 글이 가장 크다. 듣고 답하는 데 집중하게 한다.
- 움직임은 넣지 않는다. 점수가 올라가는 효과, 반짝임, 축하 표시, 이모지, 캐릭터 같은 게임 느낌의 장식은 쓰지 않는다.

## 글꼴

- Pretendard 하나만 쓴다(npm `pretendard` 1.3.9로 고정, SIL Open Font License 1.1. 앱에 넣어 쓰는 것은 허용되고, 글꼴 파일만 따로 파는 것은 안 된다). 한글과 숫자가 고르고 화면에서 읽기 편하다.
- 크기: 본문 16px(줄 간격 1.7), 안내·이름표 14~15px, 카드 제목 18px, 화면 제목 22px, 질문 글 22~24px, 고칠 한 가지의 목표 20px.
- 점수 숫자는 고른 폭 숫자(tabular-nums)로 둔다.
- 이름표를 대문자나 넓은 자간으로 꾸미지 않는다.

## 배치

- 가운데 한 줄(최대 680px), 글은 왼쪽 정렬. 375px 화면에서는 양옆 16px 여백, 가로로 넘치지 않게 한다.
- 버튼은 높이 44px 이상(손가락으로 누르기 쉽게). 주 버튼은 초록 바탕, 보조 버튼은 테두리만.
- 키보드로 옮겨 다닐 때 초록 테두리(3px)가 보이게 한다.

## 지키는 것

- 기능, 계산, 서버 코드, 화면 문구는 바꾸지 않는다. 안내 문구(연습용 참고 점수, 구글 서버 전송, 카메라 영상, 설계 값, 즉흥 발표)도 그대로 둔다.
- 상태 표시(판정, 멈춤, 시선 낮음, 빠름, 건너뜀, 읽지 않음, 노란 인용)는 색만이 아니라 글자로 보인다. 지금처럼 글자가 먼저이고 색은 돕는 역할이다.
- 개발용 확인 칸은 꾸미지 않는다.
- 밤에 정한 것: 아이콘 묶음(lucide-react)은 넣지 않는다. 버튼 글자만으로 뜻이 분명하고, 꾸밈이 늘면 "차분한 연습실"에서 멀어진다.
- 밤에 정한 것: 리허설 결과에서 코치 피드백 영역(가장 먼저 고칠 한 가지가 들어 있음)을 점수 카드보다 위로 옮긴다. 분위기의 "점수보다 다음에 고칠 한 가지가 먼저"를 따르기 위해서다. 글자와 기능은 그대로이고 놓는 순서만 바뀐다.

## 다듬기 전 화면 목록과 비교 (prompt-log "지금 화면 목록")

화면 문구와 버튼은 하나도 바꾸지 않았다(page.tsx에서 바뀐 것은 리허설 결과의 코치 피드백 위치 한 곳). 확인 방법: 각 화면을 375px(어두운 화면, 밝은 화면)과 700px(밝은 화면)로 띄워 보았고, 모두 가로로 넘치지 않았다. 리허설 준비 화면은 실제 앱으로, 나머지는 실제 화면의 스타일 이름에 예시 내용을 넣어 확인했다(밤에는 API 호출을 아끼려고 질문·평가를 실제로 받지 않았다).

| 화면 | 그대로인 것 | 바뀐 모양 |
|---|---|---|
| 입력 | 대본·주제·듣는 사람·제한 시간, 오류 안내, 질문 받기·리허설 하기 | 흰 종이 한 장 안에 모음, 입력 칸·버튼 높이 44px, 오류는 빨간 왼쪽 선 |
| 질문 준비 중·실패 | 문구, 다시 시도·대본 고치기 | 같은 종이 모양 |
| 질문 연습 | 질문 번호, 질문, 다시 듣기, 내 답, 듣는 중, 받아쓰기 안내, 버튼 5개 | 질문 글이 가장 큼(24px, 좁은 화면 21px), 질문과 답 사이 가는 선 |
| 최종 평가 | 총평, 잘한 점·고칠 점(기준, 인용, 설명, 이렇게 말해 보기), 노란 인용과 안내 글, 답변 평가 항목 전부, 참고 의견 안내 | "이렇게 말해 보기"가 연한 초록 판, 답변 평가는 넓은 화면에서 두 칸 |
| 리허설 준비·중 | 안내, 카메라(선택)와 안내, 받아쓰기 선택지, 대본, 리허설 소리 안내, 시간·말하는 중·받아쓰기 켜짐, 얼굴이 안 보여요 | 대본이 보면대처럼 큰 글(18px, 줄 간격 넓게), 시간이 큰 글 |
| 끝까지 읽었나요? | 질문, 안내, 예·아니요 | 같은 종이 모양 |
| 리허설 결과 | 말투 점수, 문장별로 보기(표시 글자, 기준, 구간별 말 속도, 군말·정확도 낮음), 얼굴 행동 점수와 연습용 참고 점수 안내, 코치 피드백, 설계 값 안내, 즉흥 발표 안내 | 코치 피드백이 맨 위로, "가장 먼저 고칠 한 가지"가 유일한 강조 판(굵은 초록 선, 목표 20px) |

- 상태 표시: 판정은 글자(좋음 등), 멈춤·시선 낮음·빠름·건너뜀·읽지 않음은 둥근 표시 안 글자, 노란 인용은 "대본에서 찾지 못한 문장이에요" 글이 함께 보인다.
- 아침에 확인할 것: 실제 질문·평가·리허설 결과로 본 모습, 시스템 설정을 밝은 화면으로 바꿨을 때, 휴대폰 크기.
- 알고 있는 작은 점: 번호 목록(잘한 점, 고칠 점)은 전부터 번호가 보이지 않는다(목록 칸 배치 때문). 이번에 고치지 않았다.
